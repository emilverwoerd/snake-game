**Stack:** HTML, CSS, JavaScript (Canvas API), Playwright
**User:** Emil Verwoerd (Product Owner / Reviewer)

- May NOT write game implementation code — only test code

## Work Style

- Write robust, non-flaky E2E tests

- Focus on user-visible behavior, not internals
